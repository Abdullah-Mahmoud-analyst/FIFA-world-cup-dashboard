# FIFA-world-cup-dashboard
Designed and developed a professional interactive dashboard using Microsoft Power BI to analyze FIFA World Cup data in a clear and engaging way. The project transforms raw data into actionable insights, enabling users to explore and evaluate the performance of teams and players through interactive visualizations.
